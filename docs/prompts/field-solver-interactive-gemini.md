# Field Solver Interactive Prompt for Gemini

## 用途

请实现一个可以嵌入 Astro Markdown 笔记的前端交互页，用来解释“通用场求解器”的基本原理，并分别可视化 FDM、FEM、BEM 三类数值方法。这个页面会通过 iframe 嵌入到 `src/content/notes/ML-4-RCX.md` 的“场求解器”小节中。

请一次性完成可运行的静态前端代码，不要先反问问题。

## 教学目标

用户已经知道一点 RCX 和寄生电容，但不理解场求解器。页面目标是让用户形成这条主线：

```text
导体几何 + 介质参数 + 边界电压
-> 求空间电势 phi
-> 电场 E = -grad(phi)
-> 导体表面法向电通量积分得到电荷 Q
-> 用 Q = C U 反推出电容矩阵
```

请在界面中解释这些专有名词：

- 场求解器：把几何结构和材料参数转成电磁场问题并数值求解的软件。
- 电势 phi：空间中每个点的“电压高度”。
- 电场 E：电势下降最快的方向，等于 `-grad(phi)`。
- 法向通量：电场穿过导体表面的强弱，用来计算表面电荷。
- 电容矩阵：描述每个导体加电压后，各导体上出现多少电荷的矩阵。
- FDM：Finite Difference Method，有限差分法，把空间切成规则网格，用相邻格点近似微分。
- FEM：Finite Element Method，有限元法，把空间切成三角形/四面体等单元，在每个单元里用简单函数近似电势。
- BEM：Boundary Element Method，边界元法，只离散导体和介质边界，把未知量放在表面上。

## 四个模块规格

### 1. 通用场求解器

做一个抽象流程可视化。

画面元素：

- 一个简化二维截面：左侧导体设为 `1 V`，右侧导体设为 `0 V`，下方是 substrate 或参考地。
- 背景显示电势等值线或颜色热力图。
- 用箭头显示电场方向，从高电势指向低电势。
- 在导体表面画出若干短法向箭头，表示通量积分。
- 右侧讲解面板显示：
  - `输入：几何、介电常数 epsilon、边界电压`
  - `求解：div(epsilon grad phi) = 0`
  - `电场：E = -grad(phi)`
  - `电荷：Qi = integral epsilon E dot n dS`
  - `电容：Q = C U`

交互：

- 一个滑块调节左导体电压 `0.5 V` 到 `2.0 V`。
- 一个滑块调节介质相对介电常数 `epsilon_r`，范围 `1` 到 `8`。
- 面板中显示一个简化电荷估计值 `Q ~ epsilon_r * V * scale`，明确标注“概念估计，不是精确求解”。

### 2. FDM 有限差分

做一个规则网格上的 Laplace relaxation 教学演示。

画面元素：

- 规则方格网格。
- 左导体格点固定为 `1 V`，右导体格点固定为 `0 V`。
- 内部格点用颜色表示电势。
- 当前更新的一个格点高亮。
- 用小公式显示：

```text
phi(i,j) = [phi(i+1,j) + phi(i-1,j) + phi(i,j+1) + phi(i,j-1)] / 4
```

交互：

- `单步迭代`按钮：执行一次或一小批 relaxation 更新，并移动高亮格点。
- `自动迭代`按钮：开始/暂停动画。
- `重置`按钮。
- 滑块 `网格密度`，至少支持 `16x16`、`24x24`、`32x32` 三档。

讲解重点：

- FDM 的核心是“用周围格点平均值逼近 Laplace 方程”。
- 规则网格容易实现，但复杂曲线边界会变成台阶状。
- 网格越密，越接近连续场，但计算量变大。

### 3. FEM 有限元

做一个三角网格和局部基函数的概念可视化，不要求实现完整 FEM 求解器。

画面元素：

- 同样的两个导体截面，但空间被划成不规则三角形。
- 导体边界处三角形更密，远离导体更疏。
- 点击或自动高亮一个三角形单元，显示它的三个节点。
- 在高亮三角形内用颜色渐变表示“单元内用简单函数近似电势”。
- 显示“局部刚度矩阵 -> 组装成全局线性方程”的流程箭头。

交互：

- `显示/隐藏局部单元`按钮。
- 滑块 `边界加密程度`，改变导体附近三角形数量或视觉密度。
- 鼠标悬停三角形时显示短标签：`单元 element`、`节点 node`、`边界条件 boundary condition`。

讲解重点：

- FEM 适合复杂几何和材料分区。
- 它不是直接在格点上取平均，而是在每个单元内假设一个简单形状函数，再把所有单元组装成方程。
- 代价是需要网格生成和求解大型稀疏线性方程。

### 4. BEM 边界元

做一个“只离散边界/导体表面”的可视化，不要求实现完整 BEM 求解器。

画面元素：

- 画两个导体和一个介质边界。
- 只在导体表面和边界上切分 panel，不填满整个空间网格。
- panel 上显示未知表面电荷密度 `sigma`。
- 用从一个 panel 指向其他 panel 的曲线/箭头表示“每个边界片都会影响其他边界片”。
- 显示一个小矩阵示意：`A sigma = V`。

交互：

- 滑块 `panel 数量`，显示 panel 变多时表面切分更细。
- `显示影响线`开关。
- 点击一个 panel，高亮它对其他 panel 的影响。

讲解重点：

- BEM 对无限开放空间很自然，因为不用把整个空气区域都网格化。
- 它常用于 3D 电容抽取类问题。
- 缺点是矩阵通常更稠密，每个 panel 可能影响很多 panel。

## 必须包含的对比表

在界面中放一个紧凑对比表，当前模块切换时可保留在面板下方：

```text
方法 | 离散什么 | 最直观优点 | 最明显代价
FDM | 规则体网格 | 简单、好理解 | 曲线边界台阶化，网格多
FEM | 不规则体网格 | 适合复杂几何/材料 | 网格生成和组装更复杂
BEM | 边界/表面 panel | 开放空间和导体表面问题自然 | 稠密矩阵，远场相互作用多
```
