Explanation:

• Area: Carea comes from εK/d, so changing layer distance changes the area capacitance density.

• Fringe: Magic's atan model uses α proportional to Carea, so smaller d makes fringe field concentrate faster.

• Sidewall: Target right edge is split into segments. Each segment couples to the nearest opposing edge within the shared halo.
